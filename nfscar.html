01 / ESTUDO ACADÊMICO

NFSCars Marketplace automotivo.

Projeto desenvolvido durante minha formação acadêmica, com o objetivo de praticar arquitetura da informação, organização de interfaces e desenvolvimento front-end.

  • UX/UI
  • Figma
  • Bootstrap
  • HTML
  • CSS
01

O projeto

O NFSCars surgiu como um projeto acadêmico voltado à criação de uma plataforma digital para o segmento automotivo.

A proposta foi desenvolver uma interface que apresentasse produtos de maneira organizada e facilitasse a navegação entre as diferentes áreas da plataforma.

Durante o desenvolvimento, pude praticar conceitos estudados em sala de aula relacionados à experiência do usuário, arquitetura da informação e desenvolvimento de interfaces.

02

O que desenvolvi

  • Organização da arquitetura da informação
  • Estruturação dos fluxos de navegação
  • Criação de wireframes
  • Construção das interfaces no Figma
  • Definição da hierarquia visual
  • Implementação utilizando HTML e CSS
  • Utilização do Bootstrap
03

Aprendizados

Este projeto foi importante para colocar em prática conhecimentos que estou desenvolvendo durante minha formação em Sistemas para Internet.

Além de trabalhar a parte visual da interface, pude compreender melhor a relação entre organização das informações, navegação e implementação front-end.

O projeto também me ajudou a identificar pontos que quero continuar estudando e aprimorando ao longo da minha formação.
