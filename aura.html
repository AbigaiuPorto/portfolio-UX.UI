02 / ESTUDO CONCEITUAL

Aura Modas Interface para moda.

Projeto conceitual desenvolvido durante meus estudos para praticar composição visual, hierarquia de informações e criação de interfaces no Figma.

  • UX/UI
  • Figma
  • UI Design
01

O projeto

O Aura Modas foi criado como um exercício de design de interface para uma marca fictícia de moda.

A proposta foi desenvolver uma página inicial visualmente organizada, explorando tipografia, composição e hierarquia das informações.

O projeto foi desenvolvido no Figma como parte da minha prática acadêmica em UX/UI Design.

02

O que pratiquei

  • Estruturação da página inicial
  • Organização das informações
  • Hierarquia visual
  • Escolha e aplicação de tipografia
  • Composição visual
  • Design de interface
  • Prototipação no Figma
03

Aprendizados

O desenvolvimento do Aura Modas me permitiu experimentar diferentes possibilidades de composição e entender melhor como pequenos detalhes podem influenciar a percepção de uma interface.

Também foi uma oportunidade para praticar o uso do Figma e aprimorar minha atenção à tipografia, espaçamento e hierarquia visual.

Como estudante, considero esse tipo de projeto importante para construir repertório e continuar evoluindo meu processo de design.
